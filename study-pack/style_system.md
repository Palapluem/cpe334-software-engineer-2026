# Writing and visual system

- A4 portrait with embedded Sarabun for Thai and English; 10 pt body text.
- Lesson flow: why the topic matters → core distinction → method/artifact → one worked example → checks and exam connection.
- Keep one canonical explanation per concept. Later cases apply it and point back instead of restating the definition.
- Retain standard English engineering terms and define them once in the glossary. Use short Thai sentences for the explanation.
- Distinguish lecture authority, exam blueprint, applied example, explanation and assumption. Never turn a missing value into a source fact.
- Prefer editable vector diagrams when relationships matter. Keep labels inside nodes, preserve whitespace, route arrows around text and test the exported PDF at full size.
- Use consistent colors: blue for artifacts/architecture, green for accepted work, purple for policy/role, orange for ambiguity/risk, crimson for major sections.
- For diagram semantics and the longer writing rules, see `docs/WRITING_AND_DIAGRAM_GUIDE.md`.
