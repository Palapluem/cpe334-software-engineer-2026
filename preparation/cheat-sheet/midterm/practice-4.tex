\topic{คำสั่ง: แทนชื่อใน < > ด้วยค่าจากโจทย์}
\par\code{git status}: branch/staged/unstaged/untracked; อ่านอย่างเดียว. \code{git diff}: tracked worktree เทียบ index (ไม่รวม untracked). \code{git diff --cached}: index เทียบ HEAD
\par\code{git add <files>}: stage เฉพาะชื่อไฟล์; ยังไม่ commit. \code{git commit -m "<msg>"}: บันทึก index เป็นลูก HEAD และเลื่อน current branch; ไม่ push
\par\code{git branch <b>}: สร้าง branch ที่ HEAD; HEAD/ไฟล์เดิม. \code{git switch <b>}: ย้าย HEAD/ไฟล์เมื่อ clean; ไม่เลื่อน branch pointer
\par\code{git merge <ref>}: รวมเข้า current; FF เลื่อน ref, แยกสายสร้าง 2 parents; source คงเดิม. \code{git merge --ff-only origin/<b>}: ยอมเฉพาะ FF
\par\code{git fetch origin}: รับ commits/เลื่อน origin/* เท่านั้น. \code{git push origin <b>}: ส่ง branch/อัปเดต origin/b; local HEAD/ไฟล์เดิม
