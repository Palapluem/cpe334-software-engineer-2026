\topic{Git: graph = ancestry + pointers}
\k{HEAD → current branch → commit}; เมื่อ clean จะได้ working tree ตาม HEAD; origin/* คือ remote-tracking ref \r{สถานะ remote ที่ local รู้ล่าสุด ไม่ใช่ GitHub แบบสด}; tag ชี้ commit คงที่
\k{switch}: เปลี่ยน HEAD/working tree ไม่เลื่อน branch; \k{commit}: สร้างลูกของ HEAD แล้วเลื่อน \r{branch ปัจจุบัน}; \k{merge}: รวมเข้า branch ปัจจุบัน ไม่เลื่อน source
\k{FF}: current เป็น ancestor ของ target → เลื่อน current ไม่สร้าง commit; \k{3-way}: แยกสาย → commit ใหม่ 2 parents; \r{graph ไม่บอกว่าจะมี file conflict}
